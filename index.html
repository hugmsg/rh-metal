☁️ Synchronisation Supabase

Envoie vos salariés (stockés localement) vers la base Supabase partagée avec le module Pointage, pour les rendre visibles sur tous vos appareils. Un salarié déjà présent (même nom/prénom, par ex. déjà créé via le kiosque Pointage) sera enrichi plutôt que dupliqué. Au chargement, l'app récupère automatiquement les données Supabase si elles existent déjà.

💾 Sauvegarde & Restauration

Exportez un fichier JSON pour sauvegarder toutes vos données (salariés, paramètres, taux CCM personnalisés). Pour synchroniser entre appareils, transférez ce fichier et importez-le sur l'autre appareil.

ℹ️ L'import remplace toutes les données actuelles. Faites un export avant d'importer.

ℹ️ Pense-bête kiosque / badge NFC (admin)

Lien du kiosque strict (à mettre sur l'appareil du Raspberry Pi, jamais l'URL normale) :
https://rh-metal.vercel.app/?kiosk=1

Lancer le pont du lecteur de badge (PC de secours si le Pi est en panne) : dossier Google Drive Pro SONOTRAD/RH/RH-Metal/nfc-bridge/dist/, double-clic sur nfc_bridge.exe.

Procédure détaillée pas-à-pas pour un collègue non technique : nfc-bridge/PROCEDURE_URGENCE.md.
